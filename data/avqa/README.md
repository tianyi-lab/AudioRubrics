# AVQA training data with static rubrics

Place here:

- `train_with_rubrics.json` — AVQA training samples in the format
  `{id, file_name, question, answer, answer_full, solution, audio_path, ...}`,
  referenced by `src/datasets_evolve.json` (edit that file to point at your copy).
- Static rubric annotations `rubrics_avqa_train.jsonl` — one line per sample:
  `{sample_id, rubrics: [{id, category, text, weight}, ...]}` with 5 rubrics whose weights sum to 1.

The rubric annotations for the full AVQA training set (40,380 samples) will be released as a
HuggingFace dataset; audio files follow the original [AVQA](https://mn.cs.tsinghua.edu.cn/avqa/)
license and must be obtained from the source.

Static rubrics were generated by prompting a strong audio judge (Gemini) with the audio, question,
and answer; see the paper's appendix for the exact prompt.
